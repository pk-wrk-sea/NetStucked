## Usage

- MAC Checker: paste CLI output; nothing happens until Check. It then extracts supported MACs, preserves line order and same-line IP mapping, and queues manufacturer lookup. IP Address is hidden when no IPs are detected. Multiple IPs/MACs on one line remain explicitly ambiguous. Maximum 512 rows/128 distinct MACs; vendor API cache/rate handling is retained.
- DNS Resolver: optional Include IPv6 DNS servers applies to active-adapter auto-selection (default off). It is independent of AAAA records; explicitly entered custom IPv6 resolvers remain supported. Answer cells wrap, rows grow with a bounded scrollable cell, and wider saved DNS columns remain adjustable. Ctrl+wheel zooms all result grids/read-only result text; Ctrl+0 resets, scale 70–200%. Input/sidebar remain separate; the embedded website uses its browser zoom.
- URL Checker: paste your personal VirusTotal key into its PasswordBox and Save key securely, then Check URL. Existing report counts/date/source/errors display inside the app. Palo Alto tab → Open Test A Site → Copy URL/paste into the provider form → complete any provider verification → Search. Provider website results remain inside that page.
- Monitoring: New → name/host/group → choose ICMP/TCP/SNMP. Default ICMP 10s/SNMP 30s, failure 3/recovery 2. Set SNMP version/port/security, enter temporary credentials or use a saved protected entry, then Test SNMP. Choose up to 32 discovered interfaces; select system/interface/bandwidth/errors/custom numeric OIDs. Save credentials securely and Save configuration, then Start. Only started entries resume on next launch; Stop clears that intent. Up to 50 configured devices, eight active collectors and globally paced SNMP request admission. Larger interface sets/slow responses can lengthen actual polling cadence; actual check times remain visible.
- Maintenance suppresses new incidents/local alerts. Windows notification/sound is local and configurable; per-device/kind/direction alert cooldown is five minutes. History is separately versioned monitoring.json with seven-day closed-incident retention and 5000-record cap, not a SQLite migration. Availability is based on actual observed checks, excluding observation gaps. Incident span is elapsed wall time; gaps are recorded separately.
- X/Alt+F4 hide the app to System Tray and continue collection. Restore or double-click the tray icon; explicit tray Exit drains work. Relaunching the same data profile restores the existing instance rather than starting duplicate collectors. Sleep/network unavailability resets evidence/counter baselines and remains distinct from a device outage. Update handoff requests real Exit and preserves Start intent.

SNMP exposes read-only observations and issues GET/GETNEXT only. Counter32 rate is withheld when the possible observation window can wrap multiple times; use shorter intervals/high-capacity v2c/v3 counters. Missing/failed SNMP and stale counters are visible separately from reachability. Interface transition counts only include changes evidenced by sampled state/ifLastChange, not every physical flap between polls. Credentials/keys are not exported or written into settings/monitoring JSON.

NOT TESTED: real Cisco/authentication/OID matrices, actual VirusTotal key, successful Palo category verification through captcha, human tray/notification delivery, physical DPI/mixed monitors/accessibility, actual clean-machine install/upgrade/recovery/uninstall or prolonged/remote production capacity. Current desktop tests do not close full M04/M07/M08 acceptance.
