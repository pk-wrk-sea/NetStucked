# Terminal — approved first slice, 2026-10-19

The human asked to implement the Terminal page after Config Collector. This explicitly approves an existing-theme interactive Terminal slice, superseding the missing-mockup gate for that page. Standing GitHub distributable publication intent carries forward; additive version 0.10.0. Original canonical references and published assets remain immutable.

Scope: up to five independent tabs, real bundled xterm.js 6.0.0 ANSI/VT terminal emulation in WebView2, SSH password/private-key authentication with verified SHA-256 host pins, explicitly acknowledged Telnet, keyboard/control keys/Unicode, clipboard and multiline-paste confirmation, terminal resize and Ctrl+wheel font zoom, explicit disconnect/reconnect/close, nonsecret saved connection profiles. No automatic connect/reconnect/credential submission on startup. Passwords/passphrases are memory-only; private-key files are explicitly chosen, never copied into app storage. No automatic credential fallback. Telnet logs in interactively in its console; resize is local display only. No session recording/export, Serial, SFTP, splits, snippets or scheduled commands in this first slice.

Architecture: Core owns immutable request/profile, session lifecycle, bounded input/output and generation IDs; Infrastructure owns pinned Tmds.Ssh sessions, raw Telnet/IAC and separate versioned nonsecret profile storage; Desktop MVVM owns tabs/commands and WPF owns an isolated persistent terminal renderer. A single local WebView holds independent bounded xterm buffers; remote bytes enter only xterm's parser, never HTML/JavaScript execution. No CDN or remote page assets. Block outbound resources/navigation, downloads, permissions, new windows, OSC52 clipboard writes and link navigation. Trusted-origin messages are size/type/session checked. Input/output queues and per-message chunks are bounded; xterm write acknowledgements provide renderer backpressure. Changing pages retains tabs/emulator state; Exit/update drains sessions before WebView disposal. Browser failure disconnects sessions.

State: Disconnected → Connecting → Connected → Disconnecting → Disconnected; connection/read/write failures → Failed after cleanup. Reconnect is an explicit user action and creates a fresh generation; stale output/input acknowledgements cannot affect it. Closing a tab cancels and awaits transport/read/write/renderer cleanup before removal. No remote commands are sent automatically after SSH login. Terminal operator keystrokes/pastes may execute commands; tests never target the working network.

Validation plan: Core lifecycle/queue/limits/snapshot/cancel/stale-generation/input UTF-8/paste policy; protected secret exclusion and profile corruption handling; actual owned SSH host-pin/password/key/resize/ANSI/control-key/disconnect and owned raw Telnet IAC; actual WebView/xterm screen model (cursor/erase/colors/alternate screen/Unicode), tab isolation, clipboard guard, output acknowledgements, resize/theme/navigation and shutdown. Report mock, loopback, rendered-WPF and real-device/manual acceptance separately. SSH library transport alone is not terminal-emulation acceptance.

Real Cisco/other vendor devices, unusual terminal/auth variants, physical/mixed DPI, accessibility and clean-machine Setup remain NOT TESTED unless separately performed. Broad A01 acceptance stays open.
