## Corrections found during verification

- Independent workbook validation exposed a missing default named style; the export now defines Normal explicitly and opens without reader warnings.
- A retained numeric WPF SelectedValue could appear empty after changing files/tab recreation although the model was mapped. Mapping selectors now bind to objects in the current header list, ignore transient null resets, and notify on header replacement. Actual displayed Hostname selection is asserted in both themes.
- One full-suite run exposed the pre-existing SNMP owned-agent teardown race: Windows can report `SocketException(OperationAborted)` while the fixture cancels/disposes its UDP socket. The test fixture now accepts only OperationAborted/Interrupted **when its own stop token is cancelled**. Active protocol errors are still failures; production Monitoring/SNMP logic is unchanged. The failed run is retained in `unit-acceptance.log` / `cve-ips-acceptance.trx`; final rerun results are recorded below.
