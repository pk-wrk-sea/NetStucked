# Collector / Inventory revision — 2026-10-22

Approved by the human in this chat: use a bundled Python Netmiko worker for explicit-start, bounded parallel collection; Cisco IOS XR, NX-OS, IOS-XE, IOS and Huawei VRP Switch/Router profiles; automatic IP + observed-hostname filenames; optional saved usernames only; memory-only passwords with a Show checkbox. Replace manual Collector pins with explicit first-use/changed-key review before authentication. Saved trust is nonsecret, never automatic acceptance. Remove the Terminal feature. Replace the appearance dropdown with a Dark-mode switch. Rename MA Inventory to Inventory and support the supplied component-level Excel layout, nullable fields and reviewed export/edit/import with stable identities. Shared IP/hostname must not merge chassis, line cards or power supplies.

Implementation and verification are tracked separately. Tests use owned loopback fixtures and isolated settings, never the working network or installed profile. Physical vendors/AAA, DPI/accessibility and Setup acceptance remain open. Existing raw evidence, saved host-key files, public tags and assets are preserved. New vendor collection does not imply new topology/CVE parser support.

Collector design: WPF owns bounded jobs and protected captures; one packaged isolated worker owns one device session. Credentials travel only in anonymous stdin, never argv/environment/settings/files. Structured bounded stdout carries status, host-key challenges and streamed output; arbitrary device exceptions/stderr are not surfaced. Cancellation kills and awaits the owned worker. Password fallback is permitted only for explicit password rejection, never timeout, changed host identity, unsupported MFA or command failure. Each run has a separate output folder; filenames include normalized address, sanitized observed hostname and port to avoid collisions. Unknown hostname is explicit, never invented.

Inventory template columns follow the supplied image: No, Company, Location, Province, Building, Floor, Room, Rack, Hostname, IP Address, Brand, Partnumber, SerialNumber, Device Type, MA Type, SLA Type, Remark, Remark2, LDoS. A retained AssetId identifies edits; existing schema-1 files remain importable. Blank optional fields and component rows without addresses are allowed; wholly blank worksheet rows are skipped. Import previews before atomic apply and retains observed evidence separately. Duplicate IDs remain errors; duplicate IP/hostname alone are valid.

Status: implemented and published as 0.12.0. See [actual verification and open real-device acceptance](GITHUB_RELEASE_0.12.0_REPORT_2026-10-22.md).
