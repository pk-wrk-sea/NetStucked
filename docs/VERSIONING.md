# Versioning

Current integration (later human authorization, 2026-10-09): **0.5.0** combines the approved Network Info Wi-Fi slice with published **0.4.2** diagnostics. Version bump/publication were explicitly authorized; **0.5.0 is now GitHub Latest**, with 242 tests, exact WPF/native/soak/package/public checks and both Windows CI workflows PASS. [Publication report](GITHUB_RELEASE_0.5.0_REPORT_2026-10-09.md). See [0.5.0 scope](FEATURES_0.5.0.md) and [combined verification](QA_0.5.0.md); earlier audit/preview version and release statements below are historical snapshots. Wi-Fi hardware authentication and broader M01 routes/neighbors remain open.

`Directory.Build.props` is authoritative for the working development version, currently **0.4.1** in the separate authorized defect follow-up. The latest public release verified by this milestone audit is **0.4.0**; [release register](RELEASE_AND_VERSIONING.md) distinguishes the subjects. MSBuild generates package/informational/assembly/file metadata and the Windows manifest from the same version; publish derives Inno's version. Display informational version without its Git build suffix. Change central version and actual CHANGELOG/release history together only for authorized releases; proposed [milestone versions](PRODUCT_ROADMAP.md) do not change metadata.

Use SemVer MAJOR.MINOR.PATCH. 0.x is development; 1.0.0 is a future stable release. Compatible bug fixes increment PATCH (1.0.x), additive compatible functionality increments MINOR (1.x), incompatible public/data behavior increments MAJOR. Tags use `vX.Y.Z`. Preserve stable Inno AppId for future upgrades; never embed a GitHub token.

0.3.0+ supports explicit selected-build installation/recovery, verified versioned schema-1 settings backups and a restart helper. Public asset identity/hash/size, Windows trust and PE version are checked before execution. Unsigned builds require acknowledgement; signing/reputation are separate. No background checks/installations occur. Legacy pre-0.3.0 source/local packages retain their manual menu. Explicit retirement removed 0.2.x release/download/old Actions artifacts after verified backups; source history/tags remain. Preserve all other published assets. See [behavior](FEATURES_0.3.0.md), [publication QA](GITHUB_RELEASE_0.4_REPORT_2026-10-09.md) and [M07 acceptance](milestones/M07_UPDATES_RECOVERY.md). Installer compilation does not prove machine recovery; JSON compatibility does not prove future SQLite rollback.
