# 0.12.0 — parallel Netmiko Collector and editable Inventory

Human authorization: 2026-10-22 chat and [recorded design](COLLECTOR_INVENTORY_2026-10-22.md). This supersedes mandatory manual Collector pins and retires the Terminal desktop feature. Standing distributable publication intent remains in effect; prior public assets are immutable.

- Collector uses bundled isolated Python 3.13.17, Netmiko 4.8.0 and Paramiko 4.0.0, with hash-locked wheels, verified PSF runtime publisher and retained licenses. No global Python installation is required.
- Explicit Start only, up to 256 targets and 1–8 parallel workers (default 2). Profiles: Cisco IOS, IOS-XE, IOS XR, NX-OS and Huawei VRP Switch/Router, with prior ASA/Aruba/combined profile aliases retained. Optional target syntax `profile=ios|ios-xe|ios-xr|nxos|huawei` enables mixed batches and selects that device's default read-only commands; no automatic platform discovery.
- Each worker owns one live transport. Host trust uses Accept Once / Accept & Save / Cancel, saved matching recognition and explicit changed-key review before SSH authentication. The existing nonsecret known-host database is retained, including its legacy filename. There is no automatic accept-all. Only explicit password rejection permits AUTH2; keyboard-interactive/MFA/partial authentication, trust errors, timeouts and command errors do not.
- Strong AES CTR/GCM and SHA-2 MACs; SHA-1 KEX, SHA-1 MAC, CBC/3DES and SHA-1 RSA/DSS negotiation are excluded. No negotiation weakening or device configuration changes. Huawei's upstream automatic configuration-security confirmations are deliberately disabled. Read-only commands plus approved session preparation are guarded; no confirm answers, config mode or command replay.
- Passwords/enable secrets remain in memory and anonymous stdin, never argv/environment/settings/logs/files. Show passwords is a view-only checkbox and all secret controls clear immediately on Start/navigation. Save usernames is explicit; Forget usernames removes those saved names.
- Output is streamed/redacted/bounded into per-run Windows-user/SYSTEM-only folders. Completed TXT/JSON names start with `<address> <observed hostname>`, with nondefault port/collision suffixes. Unknown hostnames are explicit. Evidence hashes/history remain separate; configurations may themselves contain device secrets. Cancel kills and awaits the owned worker.
- MA Inventory is renamed Inventory. The supplied component table is represented by No, Company, Location, Province, Building, Floor, Room, Rack, Hostname, IP Address, Brand, Partnumber, SerialNumber, Device Type, MA Type, SLA Type, Remark, Remark2 and LDoS. Optional fields may be blank, including hostname/IP for spare components. Shared IP/hostname does not merge distinct rows.
- XLSX export/template has filters, frozen headers and hidden stable AssetId/legacy fields. Versioned schema 1 and plain recognized headers import. Blank rows are skipped; present blank cells clear values; missing columns preserve existing fields on updates. AssetId identifies edits; a unique existing serial can propose an explicit reviewed update when ID is blank. No ID/unique serial match means Add. Duplicate/ambiguous identity remains an error. Import is previewed and atomically applied; observed evidence is preserved separately.
- LDoS is distinct from contractual MA start/end. Old JSON receives empty additional fields; old schema-1 workbooks remain importable. Older app versions may discard new optional fields when saving; downgrade preservation is not claimed. Export/backup before recovery.
- Dark-mode switches replace both the header and Settings dropdowns. Follow Windows remains an optional Settings checkbox. Terminal navigation, workspace, emulator surface and distributed xterm assets are removed; retained historical transport/trust tests do not expose a Terminal feature.

Acceptance is tracked in [QA](QA_0.12.0.md). Owned software-profile success is not real vendor/AAA acceptance; no new IOS XR/Huawei topology/CVE parser support is claimed. No Setup is executed during development.
