# 0.10.0 - Terminal

Human authorization: "ทำหน้า terminal ต่อเลย" on 2026-10-19, after Config Collector. Implement the existing-theme first Terminal slice and retain the earlier request to publish completed work as a distributable GitHub update. The broader A01 backlog is not complete. See [design/lifecycle contract](TERMINAL_2026-10-19.md) and [actual verification](QA_0.10.0.md).

- Real offline xterm.js 6.0.0 with fit 0.11.0 inside the existing WebView2 dependency; bundled MIT licenses, verified upstream integrity and per-file hashes. No CDN or npm runtime is required on the user's machine. Microsoft Edge WebView2 Runtime is required.
- Up to five independent terminal tabs with a resizable connection panel. Navigation and Tray hiding preserve sessions; closing a connected tab asks to disconnect. Exit/update cancels and awaits all sessions. Connect after Disconnect is the explicit reconnect action; no startup or automatic reconnect.
- SSH supports a single password attempt or an explicitly selected encrypted/unencrypted **OpenSSH** private-key file. Other private-key file formats, agents/certificates and MFA are not supported in this slice. Require an independently verified SHA256 host pin. Unknown/changed keys fail before authentication and report the observed pin for verification. No host-key bypass, fallback credentials or weakened algorithms.
- Explicitly acknowledged plaintext Telnet connects directly to the device console, with interactive login and IAC parsing. Terminal resize is sent to SSH; Telnet resize adjusts the local display only.
- ANSI colors, cursor/erase/alternate screens, UTF-8, keyboard/control input, Copy/Paste, multiline confirmation and Ctrl+wheel font zoom (8-28px), Ctrl+0 reset. A paste can contain at most 65,536 characters; NUL/escape/other controls are blocked except CR/LF/TAB. No automatic commands after login.
- Save/delete up to 100 nonsecret profiles in separate schema-1 `terminal-profiles.json`; no migration of existing application settings. Host, port, protocol, username, fingerprint, auth mode and key path are metadata. Password/passphrase fields clear on Connect or tab changes; values are not persisted. A key is read only for the connection and never copied into the application profile.
- Bounded 64 x 4KiB input/output queues, five tabs and 5000 scrollback lines per terminal. Each output write waits for the actual xterm parser callback. Stale session generations are rejected. Input saturation closes the connection with a visible warning, so it cannot silently accept a partial command stream.
- Remote text enters the terminal parser only. Block external navigation/resources, downloads, windows, browser permissions and remote OSC52 clipboard writes. No active hyperlinks, session recording, snippets, split panes, SFTP, Serial or scheduling.

Usage: open Terminal, enter host/port and SSH username/password or OpenSSH key, enter a fingerprint verified through the device owner, then Connect. A missing pin deliberately blocks the connection and shows the observed fingerprint. For Telnet, select Telnet and acknowledge plaintext traffic, then log in through the console. Save a profile after disconnecting. Credentials must be supplied again for each SSH connection.

Compatibility: existing schema-1 application preferences and immutable older releases remain unchanged. Older versions ignore the separate terminal profile file; that is not a claim of full future downgrade compatibility. Original approved PNGs and scope files remain byte-identical. No Setup execution is authorized on the working machine.
